# Brand

The project is called **inkslot**, always lowercase, set in JetBrains Mono. (The repository keeps its
first name, `linkedin-scheduler`, for now.) LinkedIn's brand rules don't allow its name in a product
name, so the name says what the tool does instead: ink going into its slot.

The mark is a **pen nib**: a dark cap, a blue nib, and the slit where the ink runs.

| File | Use |
|---|---|
| `inkslot-mark.svg` | The mark, on light backgrounds |
| `inkslot-mark-on-dark.svg` | The mark, on dark backgrounds |
| `inkslot-badge.svg` | The mark on a cream square (app icons, avatars) |
| `icon-512.png` | Square icon, 512×512 |
| `social-preview.png` | GitHub repository social preview, 1280×640 |

The masters, the favicons and the share images live in the website's repository
(`linkedin-scheduler-site`, `brand/` and `public/`).

## Colours

| Name | Hex | Where |
|---|---|---|
| Ink | `#101820` | The cap, the name |
| Blue | `#0066CC` | The nib, the accent |
| Blue on dark | `#4D9FFF` | The nib on dark backgrounds |
| Paper | `#F4F1EA` | Light backgrounds, the cap on dark |

## Rules

- No LinkedIn logo, and never the mark in a blue rounded square: the project is independent from
  LinkedIn and must not look like its logo.
- Do not stretch, rotate, outline or add effects to the mark.
- Smallest size: 16 px.
