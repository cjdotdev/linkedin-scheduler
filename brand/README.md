# Brand

The mark is an **L holding a square in its corner: a post resting in its slot**. One idea, two shapes.

| File | Use |
|---|---|
| `symbol.svg` | The mark, on light backgrounds |
| `symbol-on-dark.svg` | The mark, on dark backgrounds |
| `symbol-black.svg`, `symbol-white.svg` | One colour (print, stamps, monochrome UIs) |
| `lockup.svg`, `lockup-on-dark.svg` | Mark + name, horizontal (README, website header) |
| `lockup-stacked.svg`, `lockup-stacked-on-dark.svg` | Mark above the name, for narrow spaces |
| `icon-512.png` | Square icon (avatars, app icons) |
| `social-preview.png` | GitHub repository social preview, 1280×640 |

## Colours

| Name | Hex | Where |
|---|---|---|
| Ink | `#151515` | The L, the name |
| Orange | `#F24822` | The square (the post), the accent of the cards |
| Orange on dark | `#FF6633` | The square on dark backgrounds |
| Cream | `#FAF8F5` | Light backgrounds |

## Rules

- Keep clear space around the mark of at least the size of the square.
- Smallest size: 16 px for the symbol, 120 px wide for the horizontal lockup.
- The name is set in JetBrains Mono SemiBold, converted to outlines: do not retype it in another font.
- Do not use LinkedIn's blue or put the mark in a blue rounded square: the project is independent from
  LinkedIn and must not look like its logo.
- Do not stretch, rotate, outline or add effects to the mark.
